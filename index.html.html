CSE406 Software Engineering Project（軟體工程專案）

Adaptive Study Scheduler（自適應學習時間安排器）

Plan only for the time you actually have today, while tracking a weekly goal.（只根據今天實際可用的時間安排學習，同時追蹤每週目標。）

Daily Adaptive Planning（每日自適應規劃）

1. Weekly Goal（每週目標）

You only set a weekly target. You do not need to predict your whole week.（只設定每週目標，不需要提前預測整週行程。）

Today’s plan needs regeneration because the weekly goal or courses changed.（因每週目標或課程已變更，今天的計畫需要重新產生。）

2. Add Courses（新增課程）

Add your courses once. No study topics are required.（課程只需加入一次，不需要輸入具體學習內容。）

3. Course Overview（課程概況）

The weekly target is divided by difficulty, priority, and an optional near exam date.（每週目標會依難度、優先級與接近考試日期的程度分配。）

No courses added yet（尚未新增課程）

Completed This Week（本週已完成）0h

Days Left This Week（本週剩餘天數）0

4. Plan Today（規劃今天）

Enter only the time you realistically have from now until today ends.（只輸入從現在到今天結束前，實際能拿來學習的時間。）

The program never assumes you are free on Friday or Saturday. Tomorrow, open it again and enter tomorrow’s real available time.（程式不會假設你週五或週六一定有空；明天再打開程式，輸入明天實際可用的時間即可。）
A single study session is capped at 90 minutes to avoid unrealistic long sessions.（單次學習最多90分鐘，避免不切實際的超長時段。）

5. Today’s Plan（今日計畫）

Each session is limited to 90 minutes. The timer records actual study time.（每個學習時段最多90分鐘；計時器會記錄實際學習時間。）

No plan for today yet（今天尚未產生計畫）

6. Weekly Progress（每週進度）

Progress uses Actual Study Time（實際學習時間）, not just planned time. A new week starts automatically every Monday.（進度會依實際學習時間計算，而不是只看計畫時間；每週一自動開始新的週進度。）
